Which panel is yours?

Basketed prints its panel address when it starts. Paste the origin here — just the scheme, host and port, no path.

Why this exists. Every page on 127.0.0.1 looks alike to a browser extension, whatever port it is on. Without a pinned address, any local server could ask this extension for your Tesco or Amazon cookies and it would have no way to tell it apart from the real panel. Pinning the origin means it will only ever answer yours.

You only need to change this if your panel is not on the default port — Basketed picks another one when 8787 is already taken.
